Key Features
🎯

Anti-Windup PID

Custom PID implementation with integral anti-windup clamping and derivative-on-measurement to eliminate sensor noise amplification.

📅

Setpoint Scheduling

Time-varying temperature profiles — the system automatically steps through pre-programmed target temperatures across an experiment timeline.

🔌

Modbus RTU Control

Direct serial communication with the Hanmatek HM310T programmable power supply to modulate voltage and current to the Peltier module.

📡

DS18B20 Sensor Feedback

1-Wire DS18B20 digital temperature sensors providing high-resolution real-time feedback for the closed-loop control algorithm.

🖥

Live HTML Dashboard

Research-grade real-time web dashboard with temperature vs. time charts, PID output visualization, setpoint tracking, and data export.

🔬

PV Research Integration

Designed specifically to stabilize thermal conditions during photovoltaic cell characterization experiments in the IIT optoelectronics lab.

Core Algorithm
# PID Controller — Anti-Windup + Derivative-on-Measurement
class PIDController:
    def __init__(self, Kp, Ki, Kd, output_limits):
        self.Kp, self.Ki, self.Kd = Kp, Ki, Kd
        self.limits = output_limits
        self.integral = 0
        self.prev_measurement = None

    def compute(self, setpoint, measurement, dt):
        error = setpoint - measurement
          # Derivative on measurement — avoids derivative kick
        d_measurement = (measurement - self.prev_measurement) / dt
        output = self.Kp * error - self.Kd * d_measurement
          # Anti-windup: only integrate if not saturated
        if self.limits[0] < output < self.limits[1]:
            self.integral += error * dt
        output += self.Ki * self.integral
        self.prev_measurement = measurement
        return max(self.limits[0], min(output, self.limits[1]))
